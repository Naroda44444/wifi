
## 🔧 Опис проєкту

Ця програма створена з використанням бібліотеки **Tkinter** (вбудована GUI-бібліотека Python) та системної команди Windows:

```
netsh wlan show interfaces
```

Застосунок:

* 📡 Визначає поточну Wi-Fi мережу (SSID)
* 📊 Показує рівень сигналу у відсотках
* 🎨 Змінює колір індикатора залежно від сили сигналу
* 📝 Записує історію сигналу у файл `wifi_history.txt`
* ⚠️ Показує попередження при слабкому сигналі

---

## 🚀 Функціонал

### 1️⃣ Отримання даних Wi-Fi

Функція `get_wifi_data()`:

* Використовує `os.popen()`
* Аналізує результат команди `netsh`
* Повертає:

  * SSID
  * рівень сигналу (%)

---

### 2️⃣ Збереження історії

Функція `save_to_file()`:

* Записує дані кожні 5 секунд
* Додає часову мітку
* Формат запису:

```
[12:45:01] Мережа: MyWiFi, Сигнал: 78%
```

---

### 3️⃣ Головний цикл оновлення

Функція `update_loop()`:

* Оновлює дані щосекунди
* Змінює колір індикатора:

  * 🟢 >75% — хороший сигнал
  * 🟡 50–75% — середній
  * 🔴 <50% — слабкий
* Показує попередження при сигналі <20%

---

### 4️⃣ Робота з логами

* `open_log_folder()` — відкриває папку з логами
* `clear_logs()` — очищає файл історії
